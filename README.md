# Finsight — Finance Dashboard

A clean, interactive finance dashboard built with vanilla HTML, CSS, and JavaScript + Chart.js.

## Live Demo
(superb-meringue-7e5c98.netlify.app)



## Tech Stack
- Vanilla HTML, CSS, JavaScript
- Chart.js (via CDN)
- localStorage for persistence
- No framework, no build tool

## Features
- Dashboard overview with summary cards
- Balance trend line chart
- Spending breakdown doughnut chart
- Monthly income vs expense bar chart
- Transaction table with search, filter, sort, pagination
- Add, edit, delete transactions (Admin only)
- Role-based UI — Admin and Viewer
- Insights section with spending analysis
- Dark and Light mode toggle
- CSV export
- Fully responsive
